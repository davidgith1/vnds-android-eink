# Tested games

Real story packs used to test this app's two script interpreters (`vnds.ScriptEngine` for VNDS,
`nscripter.NsScriptEngine` for NScripter/ONScripter) against actual, real-world game data — not
bundled with this repo (see `.gitignore`), kept locally under `Onscripter examples/` and `VNDS
Example/` for manual/`tools/ns-trace/` testing. See `CLAUDE.md` for how to point the app or
`ns-trace` at a pack like this yourself.

**English availability** below is pulled from each title's [VNDB](https://vndb.org) entry (its
`languages` list — i.e. *some* English release/patch exists, official or fan-made; VNDB doesn't
distinguish the two at that level, so check the linked page for the specific release you want).
Titles marked "olang: en" were written in English originally, not translated.

**Script cross-check.** All three of the new guides (Kanon, Ever17, CLANNAD) were originally built
from published human-written walkthroughs, not from this repo's own VNDS-port scripts. A first
cross-check pass tried automated fuzzy-matching of the guides' day-by-day narrative descriptions
against every real `choice` command extracted from each pack -- this turned out to be unreliable
(false positives: e.g. the top match for Kanon's "decline to help Mai with her nightmare" was
actually an unrelated Ayu luggage-unpacking scene) and, more fundamentally, produced the wrong kind
of guide: narrative paraphrase of what a choice is "about" rather than the literal, quotable button
text a player can match against what's on their screen. The guides were rebuilt properly instead, by
directly tracing each pack's own script:
- **Method**: for each heroine's route, find the real `jump SEEN####.scr` dispatch chain by `grep`,
  confirm which file-chain belongs to which character (from real speaker-name density where the port
  uses literal names, e.g. Kanon; or from already-known file numbers carried over from earlier work,
  e.g. CLANNAD's `SEEN3428`/`SEEN7600`), locate the route's real `choice` commands, resolve any
  `$strS[]`/`setvar`-substituted button text back to its literal value, and read the branch-taken
  text on both sides of the choice to confirm which option is the Good End's and which is the Bad
  End's -- rather than trusting a walkthrough's claim about which one is "correct".
- **Kanon**: this rebuild also surfaced a genuine structural finding, now documented in the file's
  `generatedNote`: heroine-route selection is not one named dialog choice the way simplified web
  walkthroughs describe it (e.g. "decline to help Mai around Jan 14" does not correspond to any real
  choice in the script). The real dispatcher (`SEEN0180.scr:6415-6427`) checks cumulative affection
  flags (`intF[339]` for Shiori, `intF[450]` for Mai, a running counter `intF[392] >= 15` for Makoto,
